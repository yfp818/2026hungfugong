# Core Rules

## Coding

- Evidence first.
- Minimum changes.
- Keep existing architecture.
- Avoid unnecessary refactoring.

## Performance

- Reduce API calls.
- Reduce Supabase queries.
- Reduce Cloud Run CPU.
- Prefer Server Components.
- Avoid unnecessary Client Components.
- Avoid duplicate fetching.

## Workflow

Analyze

↓

Plan

↓

Confirm

↓

Modify

↓

Build

↓

Deploy (only if approved)

## Output

Every task reports:

- Root cause
- Modified files
- Build result
- Test method
- Cost impact
